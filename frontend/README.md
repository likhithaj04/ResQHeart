ResQHeart
ResQHeart is a full-stack MERN web application dedicated to helping stray animals by connecting adopters, donors, volunteers, and shelters on one compassionate platform.The platform enables animal adoption, donations, awareness campaigns, and an admin dashboard for managing rescue operations.
Frontend: https://res-q-heart.vercel.app
Backend: https://resqheart.onrender.com

Public Features:
ResQHeart allows users to browse pets available for adoption, submit adoption requests, donate to registered shelters, and explore awareness blogs and articles. The platform includes secure user authentication with login and registration functionality, enabling users to interact safely with adoption and donation services.

Admin Dashboard:
The admin dashboard provides authorized administrators with tools to manage pets through full CRUD operations, review and process adoption applications, manage blogs and awareness posts, view donation records and registered users, handle user messages, and onboard shelters efficiently through a centralized management interface.

Security:
The application implements robust security measures using JWT authentication stored in HTTP-only cookies, role-based access control for admin functionality, protected routes implemented with React Router, and a secure CORS configuration with credential support to ensure safe and reliable communication between the frontend and backend.

Frontend: React (Vite), React Router, Axios, Bootstrap, CSS
Backend: Node.js, Express.js, MongoDB, Mongoose
Auth & Security: JWT, HTTP-only cookies, CORS
Deployment: Vercel (Frontend), Render(backend), MongoDB Atlas
